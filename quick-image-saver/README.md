# 快存图片 v1.3.0

选择保存文件夹，鼠标移到网页图片上，点击「↓ 快存」直接存进去。

## 从旧版更新

1. 将新版 ZIP 中 `quick-image-saver` 文件夹的内容，覆盖到**原来已安装的插件目录**，保留原文件夹路径。
2. 打开 `chrome://extensions`，找到「快存图片」，点击卡片上的重新加载按钮，确认版本为 `1.3.0`。
3. 刷新设置页和需要下载图片的网页。不要卸载旧扩展；相同安装路径下重新加载可保留原目录设置。

在 Chrome 扩展内下载 B 站、YouTube 和 X 的公开视频。打开视频详情页，从扩展弹窗保存 MP4。

## 安装（桌面版 Chrome 116+）

1. 将 ZIP **解压到固定位置**，例如 `D:\ChromeExtensions\quick-image-saver`。请不要删除或移动这个文件夹。
2. 在 Chrome 地址栏输入 `chrome://extensions`，打开右上角的「开发者模式」。
3. 点击「加载已解压的扩展程序」，选中**里面包含 manifest.json 的 quick-image-saver 文件夹**，不要选 ZIP，也不要选外面的总文件夹。
4. 点击浏览器右上角的拼图图标，将「快存图片」固定到工具栏。
5. 安装后会打开设置页。点击「选择保存文件夹」，在系统窗口进入你希望的实际位置，选择文件夹并允许写入。桌面、不同磁盘和深层文件夹都可选择。
6. 点击「保存一张测试图片」，在选定文件夹中确认测试图已出现。

## 日常使用

- **先刷新已打开的网页**。新打开的普通网页不需要这一步。
- 鼠标移到图片上，点击右上角的蓝色「↓ 快存」。
- 成功后会显示文件夹名称与文件名；相同文件名会自动增加 `(1)`、`(2)` 等编号。
- 切换位置：工具栏的「快存图片」→「选择 / 更改图片保存位置」→ 选择新的文件夹。
- 每张图片在加入保存队列时记住当前文件夹。切换位置只影响之后加入的任务，已排队的图片不会被改存。
- 选择新文件夹后，获得写入授权才会正式更换保存位置；取消或拒绝授权时保留原设置，并给出提示。
- 暂停显示按钮：在工具栏扩展面板里关闭开关。
- Chrome 重启或回收权限后，如提示重新授权，打开设置页点击「重新授权当前文件夹」。

## 保存视频

1. 打开「快存图片」并开启「保存视频」。首次使用默认关闭，Chrome 重启后会记住最近的选择。
2. 打开 B 站、YouTube 或 X 的单个视频详情页，点击「保存当前视频」。视频画面右键菜单里的「保存视频」也可触发。X 时间线中的视频可先打开对应帖子。
3. 扩展在浏览器内下载和合并音视频，将 MP4 交给 Chrome 保存。文件使用 Chrome 的下载位置。弹窗会显示进度和实际路径。
4. 关闭开关后停止接收新任务，已开始的下载继续处理。其他网站上的普通 MP4、WebM 直链视频也支持右键保存。

B 站优先使用可获得的 AVC 视频和 AAC 音频，视频请求失败时自动尝试其他可用画质。平台拒绝访问或未提供可保存的格式时，弹窗会显示原因。

## 保存方式与边界

- 可以选择电脑上你有写权限的普通文件夹。严格写入所选实际目录，不另建默认子目录、不自动改存其他位置；系统保护目录可能被 Chrome 拒绝。
- **通过系统选择器选定目录**，不支持仅在输入框中填写一个绝对路径就获得写权限。界面只显示文件夹名，完整位置以系统选择器为准。
- 图片直接写入授权文件夹，不走 Chrome 下载队列，因此可能不会出现在 `chrome://downloads` 中。
- 保存网页实际加载的图片 `currentSrc`，不保证能获取网站未公开的原始大图。
- 普通 `<img>` / `<picture>` 图片、常见格式 JPG/PNG/WebP/GIF/AVIF/SVG 等均可；保留获取到的数据，不转码。格式根据图片内容确定，不把 WebP 冒充 JPG。
- 会显示按钮的图片至少为 48 × 48 CSS 像素。支持滚动、动态插入图片和普通 iframe 内的图片。
- CSS 背景、canvas 画布、封闭 Shadow DOM、浏览器内部页、Chrome 应用商店页面不在本版支持范围。
- 某些登录校验、防盗链、临时地址、图片覆盖层或网站特殊结构可能导致按钮不显示或下载失败。本扩展不会绕过网站的访问控制。
- 单张图片上限 100 MB；一次请求的网络超时为 45 秒。正在保存的任务会依次处理。
- 对扩展自身发起的保存任务，自动编号避免重名覆盖。若其他程序在同一瞬间创建同名文件，文件系统接口无法提供跨程序的完全原子保留保证。

## 隐私与权限

- 无登录、无广告、无第三方上传、无分析统计、无远程脚本。
- `http://*/*` 与 `https://*/*`：用于在网页显示图片按钮，并从图片所在服务器获取数据；必要时使用浏览器已有登录凭据。
- `storage`：在本地保存图片和视频开关、最近一次保存的图片文件名等设置。
- `offscreen`：在后台接收图片 Blob 并写入授权的文件夹。
- `contextMenus` 和 `downloads`：显示「保存视频」菜单项并使用 Chrome 下载。
- `scripting`：点击保存时读取当前页面已加载的视频信息。
- `declarativeNetRequestWithHostAccess`：为扩展自己发出的指定媒体请求补充平台需要的请求头。
- 目录授权句柄保存在扩展自己的 IndexedDB，仅在你点击保存或保存测试图时写文件。
- 卸载扩展会移除扩展设置，不会删除已保存的图片。

## 文件与开发

无需 Node.js、构建或本地辅助服务，直接加载本文件夹即可。完整源码已包含在此文件夹内。

- manifest.json：Chrome Manifest V3 配置。
- content.js：网页上的悬浮按钮和保存提示。
- background.js：消息转发与后台文档管理。
- video.js / video-sites.js / platform-download.js：视频开关、平台页面识别和 Chrome 下载状态。
- platform-resolvers.js / platform-writer.js / video-media.js：分站点读取媒体地址、下载和合并。
- writer.js / writer.html：图片获取、顺序写入。
- db.js / image-utils.js：本地目录句柄存储、图片识别和文件名处理。
- popup.* / options.* / ui.css：中文面板与设置页。

本地开发版未上架 Chrome 应用商店，使用「加载已解压的扩展程序」安装。ZIP 用于分发与备份，不能直接拖入安装。
